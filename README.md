# 💬 ChatLLM by Mr. K

An interactive ChatGPT-like app built with **Streamlit**, powered by **OpenAI GPT-4** (Mini or gpt-4o), and integrated with **Firebase** for secure Google login and chat history storage.

> ✅ Supports user authentication, live chat, and persistent history  
> 📁 Upload your slides or data files (PDF, Excel, CSV)  
> 🎨 Toggle between dark and light modes (coming soon)

---

## ✨ Features

- 🔐 **Google Login** with Firebase
- 💬 **GPT-4 Chat Interface** (uses `gpt-4-1106-preview`)
- 📂 **Chat History Saved** in Firestore (per user)
- 📁 File Upload Support (PDF, CSV, Excel, Slides) *(coming soon)*
- 🌙 Light/Dark Mode Toggle *(coming soon)*
